# Pomodoro 3D PWA

A standalone, dependency-free Pomodoro Progressive Web App designed for Android and mobile browsers.

## Features
- 3D tactile tomato timer UI
- Focus, short-break and long-break cycles
- Drag the top dial to adjust the timer
- Configurable durations and long-break interval
- Auto-start focus/break options
- Pause, resume, reset and skip
- Daily focus statistics stored locally
- Completion sound, optional ticking and vibration
- Browser notifications
- Screen Wake Lock while the timer is running
- Offline service-worker cache
- Android PWA install support
- Timer state persists using a real finish timestamp

## Deploy
This is a static PWA. Import this repository into Vercel with Framework Preset set to **Other**. No build command or environment variables are required.
